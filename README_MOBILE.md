# حارة البطل (Haret El Batal) — دليل التشغيل والاختبار على الموبايل

نموذج أولي قابل للعب (Playable Prototype) بلغة **GDScript** على محرك **Godot 4.3+**، بأصول فنية وصوتية أصلية 100% ومولدة بالكود، تعمل أوفلاين بالكامل وبحجم أقل بكثير من 50 ميجابايت.

---

## 1. التشغيل السريع على الكمبيوتر (Godot 4)
1. حمّل **Godot 4.3** (الإصدار القياسي Standard — لا تحتاج إصدار .NET).
2. افتح Godot → اضغط **Import** → اختر ملف `project.godot` من هذا المجلد.
3. اضغط **F5** لتشغيل اللعبة (`Level1.tscn` مضبوطة كـ Main Scene).

### أزرار التحكم للاختبار على الكمبيوتر
| الإجراء | لوحة المفاتيح | يد التحكم البلوتوث (Gamepad) |
|---|---|---|
| الحركة والتصويب (8 اتجاهات) | `W A S D` أو الأسهم | D-Pad أو العصا اليسرى |
| قفز / نزول من منصة | `Space` أو `Z` أو `K` | الزر السفلي (`A` / `Cross`) |
| إطلاق النار | `J` أو `X` | الزر الأيسر (`X` / `Square`) |
| تبديل السلاح (رشاش/متفرق/ثقيل) | `Q` أو `E` | `R1` / `RB` |
| تفعيل/إيقاف الإطلاق التلقائي | `F` | الزر العلوي (`Y` / `Triangle`) |

*(ملاحظة: خيار `emulate_touch_from_mouse` مفعّل، لذا يمكنك اختبار الأزرار اللمسية بالماوس مباشرة على الكمبيوتر أيضاً).*

---

## 2. التصدير والتشغيل على موبايل Android (APK)
1. داخل Godot 4: اذهب إلى **Editor → Manage Export Templates** وحمّل قوالب التصدير لإصدارك.
2. ثبّت **OpenJDK 17** و **Android SDK** (من Android Studio)، ثم أضف مساريهما من:
   `Editor → Editor Settings → Export → Android`.
3. اذهب إلى **Project → Export** — ستجد قالب **Android** مجهّزاً مسبقاً في `export_presets.cfg` مع:
   - أيقونات الـ APK الأصلية (`icon_192.png` + `icon_foreground.png` + `icon_background.png`) مربوطة تلقائياً.
   - معمارية `arm64-v8a` (حجم APK سيكون حوالي **20–28 ميجابايت فقط**).
   - اتجاه الشاشة **Sensor Landscape** وإذن **`Vibrate`** مفعّلين مسبقاً.
4. اضغط **Export Project** لإنتاج ملف `HaretElBatal.apk`.
5. انقل الملف لهاتفك الأندرويد وثبّته، وستعمل اللعبة **أوفلاين بالكامل** مع دعم الأزرار اللمسية ويد التحكم البلوتوث تلقائياً.

---

## 3. نصيحة سريعة للاختبار الفوري على الهاتف بدون بناء APK يدوي
- فعّل **USB Debugging** على هاتفك الأندرويد ووصّله بالكمبيوتر عبر USB.
- ستظهر أيقونة **Remote Deploy (أيقونة أندرويد)** في أعلى يمين محرر Godot — بضغطة واحدة تُثبّت اللعبة وتعمل مباشرة على هاتفك!
